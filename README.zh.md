## 📌 精选项目

### 🔍 [SensFinder](https://github.com/huajielong/SensFinder) ⭐ 5
> **基于LLM的敏感信息检测与分类系统**
>
> 自动识别文本中的姓名、地点、公司、组织等信息。
> 支持 OpenAI、DeepSeek 和本地模型。

### 🎬 [sora2-watermark-remover](https://github.com/huajielong/sora2-watermark-remover) ⭐ 3
> **一键去除Sora2视频水印 — YOLOv11 + LAMA**
>
> 四种操作模式：CLI命令行、Web界面、桌面GUI和Web服务。

### 🤖 [skill-evaluator](https://github.com/huajielong/skill-evaluator) ⭐ 3
> **AI Agent 技能医生 — 五维评分 + 安全网关 + 排行榜**
>
> 针对AI Agent技能的全面评估框架。

### 🎵 [music-video-creator](https://github.com/huajielong/music-video-creator)
> **AI驱动的音乐视频创作 — 从歌词到完整MV全自动生成**
>
> 集成Mureka作曲、Seedream图像生成和Whisper字幕同步。

### 💬 [chatbot-ollama-llms](https://github.com/huajielong/chatbot-ollama-llms)
> **基于Ollama的多模型聊天机器人 — FastAPI + React 全栈**
>
> 私有本地LLM部署，数据完全留在你的网络中。

### 📁 [mp4-copy-tool](https://github.com/huajielong/mp4-copy-tool)
